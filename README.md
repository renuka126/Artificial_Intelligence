# Artificial Intelligence

This repository contains the Artificial Intelligence practicals that I am working on as part of my Computer Engineering course.

The practicals mainly focus on understanding basic AI concepts and implementing different search techniques using Python.

## 📚 Practicals Covered

### Practical 01 – Intelligent Agents
Basic implementation and understanding of intelligent agents, their environment, sensors, actuators, and types of agents.

### Practical 02 – Search Techniques
Study and implementation of search techniques used in Artificial Intelligence, including uninformed and informed search methods.

### Practical 03 – Tower of Hanoi using State Space Search
The Tower of Hanoi problem is represented as a state-space search problem. The program finds a sequence of legal moves from the initial state to the goal state using search.

### Practical 04 – A* Algorithm for 8-Puzzle
Implementation of the A* search algorithm to solve the 8-Puzzle problem. The program uses `g(n)`, `h(n)` and `f(n)` values to select the best state.
